# Contributor Covenant Code of Conduct

## Our pledge
We are committed to a respectful, inclusive and harassment-free participation experience.

## Our standards
Positive behaviour includes respect, constructive feedback, openness to differing viewpoints and focusing on the project's users. Unacceptable behaviour includes harassment, discriminatory language, personal attacks, intimidation and publishing private information without permission.

## Enforcement
Maintainers clarify and enforce these standards. Report concerns privately through an appropriate contact route on the repository owner's GitHub profile. Do not publish sensitive details in a public issue.

This project follows the principles of the [Contributor Covenant](https://www.contributor-covenant.org/). Consult its current version for the complete upstream text.
